[0] 바로 쓰는 견적 계산기 (비로그인 바로 사용)

▶ 🔗 https://claude.ai/public/artifacts/71732d26-aa6f-4803-adc1-487d3b34312d
  · 로그인 없이 항목·수량·단가만 넣으면 합계·부가세·총액 자동. 회사명·로고·도장·거래처 설정 후 PDF 저장까지.
  · 내 양식으로 바꾸고 싶으면 아래 [1] 프롬프트로 새로 만드세요.


[1] 견적 계산기 만들기 (클로드 대화창에 복붙)

▶ 클로드에 그대로
  · "견적서 만드는 웹앱을 아티팩트로 만들어줘. 필요한 항목은 회사명, 견적일, 받는 곳, 항목, 수량, 단가, 금액이고, 입력하면 자동으로 합계랑 부가세 10%, 총액이 계산되면 좋겠어. 회사명이랑 로고, 도장도 업로드하면 견적서에 함께 표시되고, 최종적으로 PDF로 다운로드할 수 있게 해줘."
  → 작동하는 견적 계산기가 아티팩트로 나옵니다. 평소 쓰는 견적서 양식을 같이 첨부하면 내 양식 구조 그대로 잡아줍니다.


[2] 안 맞으면 말로 고치기 (영상에서 실제로 한 요청)

  · 빈 페이지 → "PDF로 저장하면 빈 페이지가 생겨, 이거 제외해줘"
  · 거래처 관리 → "거래처를 드롭박스로 추가·삭제·수정할 수 있는 거래처 관리 기능 넣어줘"
  · 도장·로고 → "도장이랑 로고는 표시할지 체크해서 켜고 끌 수 있게 해줘"
  · 내 업종 → "항목을 [내 업종] 기준으로 바꿔줘"


[3] 쓸 때 팁

  · 만든 견적기는 HTML로 다운로드해두면 다음에 그대로 재사용 (로컬에서 바로 열림)
  · 단위(시간·개·평·건)는 본인 업종에 맞게 한 줄 더 요청
  · 자주 쓰는 거래처는 거래처 관리에 미리 넣어두면 드롭박스로 바로 선택
