[1] 영상에서 쓴 프롬프트 (그대로 복사)

▶ ① 설정 → 개인 인텔리전스 → 요청사항 (02)
항상 두괄식, 개조식으로 답해 줘.
또는
항상 서술형으로 답하고, 마지막에 세 줄로 요약해 줘.
· 뒤에 붙여 쓸 수 있는 것: 항상 300자 이내로 답해 줘 / 답하기 전에 올바른지 한 번 검토해 줘 / 항상 전문적으로 답해 줘

▶ ② 회의 녹음 올리고 대본 만들기 (04)
이거 대본으로 정리해 줄래? 말한 사람도 나눠 줘.
· 연습하려면 meeting/회의녹음.m4a를 올리고, 결과를 meeting/대본.md와 맞대 보세요

▶ ③ 지메일 연결 뒤 (05)
어제 나한테 온 지메일 제목 알려 줄래?
· 연결 = 설정 → 개인 인텔리전스 → 연결된 앱 → Gmail

▶ ④ 캔버스가 「저는 못 합니다」라고 할 때 (07)
캔버스 기능 활용해서 본문 작성해 줘.
그래도 안 되면 → 할 수 있잖아, 다시 해 줘.

▶ ⑤ 예약 작업 (10)
매일 아침마다 뉴스를 정리해서 보고해 줘.
· 이렇게도: 매일 아침 전날 나한테 온 메일을 정리해서 요약해 줘


[2] 스킬 「회의록 담당」 넣기 (09)

젬은 2026년 11월 17일부터 스킬로 바뀌었습니다. 두 가지 길이 있습니다.

A. 영상처럼 제미나이에게 만들게 하기
  1. gemini.google.com → 왼쪽 맞춤설정 → 스킬 → 만들기 → 제미나이로 만들기
  2. 이렇게 말합니다: 「회의록을 정해진 양식으로 고정해서 받고 싶어. 회의 녹음을 넣으면 알아서 대본으로 바꾸고, 결정된 것 · 할 일(담당자 · 기한) · 정하지 못한 것으로 요약해 줘. 한국어로 만들어 줘.」
  3. 만들어진 스킬 내용이 내가 실제로 쓰는 양식과 맞는지 한 번 읽어 봅니다

B. 이 폴더의 파일을 그대로 넣기
  1. meeting-notes/SKILL.md를 엽니다
  2. 맞춤설정 → 스킬 → 만들기 → 수동으로 만들기
  3. 이름 「회의록 담당」, 요청 사항에 SKILL.md의 「# 회의록 담당」 아래 본문을 붙여넣고 만들기

쓰는 법: 새 채팅에서 @를 치고 스킬 이름을 고른 뒤 녹음 파일을 올립니다.
· 우리 팀 양식이 따로 있으면 SKILL.md의 정리 순서를 그 양식으로 바꿔 쓰세요
