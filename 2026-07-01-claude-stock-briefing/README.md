· 원/달러 환율
· 각 종목 핵심 뉴스 2~3개 (제목만 짧게)
· VOO 환산가 = VOO 종가 × 원/달러 환율

[2] 셋업 순서 — 카톡 연결부터 매일 자동까지

▶ 1단계 · 카톡 커넥터 연결
  · claude.ai → 설정 → 커넥터 → 커넥터 둘러보기
  · "PLAY MCP" 검색 → 연결 → 카카오 아이디·비밀번호로 로그인
  · 도구함에서 "카카오톡 나챗방(나에게 보내기)" 토글 ON 확인
  → 확인: "카톡으로 테스트 보내줘" → 내 카톡에 도착하면 연결 완료

▶ 2단계 · 내 종목 양식 만들기
  · 새 채팅에서 내 종목·기준을 주고 "검색해서 정리해 카톡으로 보내줘"
  · 카톡은 메시지당 200자 → 종목별로 메시지를 나눠 보내게 지침
  → [1] 프롬프트가 이 양식을 이미 담고 있음 (종목만 교체)

▶ 3단계 · 매일 자동(루틴)
  · 왼쪽 사이드바 '코드' → Claude Code 웹 → 루틴 추가
  · 지침란에 [1] 프롬프트 붙여넣기 / 이름은 'AI 주식비서'
  · 트리거 = 스케줄(매일 원하는 시각) / 커넥터에 PLAY MCP 포함
  · 만들기 → '실행'으로 한 번 테스트
  → 웹(클라우드) 루틴이라 PC가 꺼져 있어도 매일 자동 발송
