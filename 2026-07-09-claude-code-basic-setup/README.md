---

📥 스타터 팩 다운로드: https://github.com/archigent/claude-code-starter-pack (Code → Download ZIP)

[1] 스타터 팩 구성 (파일 4종)

▶ CLAUDE.md — 🔴 핵심. 클로드가 매 세션 자동으로 읽는 지침. 작업 원칙(파악→계획→실행→검수) + 내 프로젝트 규칙을 담는 허브
▶ .claude/settings.json — 매 요청마다 작업 원칙 상기 + 위험 행동 차단 훅
▶ .claude/hooks/ — no-background-guard(백그라운드 실행 차단) · debug-warn(디버그 흔적 경고)
▶ README.md — 설치법 + 각 파일이 왜 필요한지 + 내 걸로 채우는 법


[2] 설치 (3분)

▶ 1단계 · 파일 넣기
  · 팩을 통째로 본인 프로젝트 폴더 안에 복사
  · CLAUDE.md → 폴더 최상위 / .claude 폴더 → 폴더 최상위
▶ 2단계 · 훅 권한 주기
  · 터미널에서: chmod +x .claude/hooks/*.sh
  → 이거 안 하면 훅이 조용히 안 먹습니다(영상 속 함정)
▶ 3단계 · 확인
  · 클로드 코드 켜고 /hooks → 훅 잡혔는지 확인
  · 아무거나 요청 → 답하기 전에 먼저 계획을 세우면 성공


[3] 내 걸로 채우기 (CLAUDE.md 안 << >> 부분만)

▶ §1 이 프로젝트가 뭔지 — 한두 줄 (예: "동네 베이커리 온라인 판매")
▶ §2 라우팅 표 — 규칙 생길 때마다 한 줄씩 추가 (처음엔 비어도 됨)
▶ §3 말투 — 어떻게 보고받고 싶은지
