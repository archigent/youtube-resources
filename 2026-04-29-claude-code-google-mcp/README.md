[2] 셋업 — claude.ai 커넥터 5단계 (npm 설치 X)

▶ ① 브라우저에서 claude.ai 로그인
▶ ② 설정 → 커넥터 메뉴 진입
▶ ③ "커넥터 둘러보기" 클릭 → Gmail / Google Drive / Google Calendar 선택 → +
▶ ④ 구글 로그인 팝업 → 계정 연동 (3개 각각)
▶ ⑤ Claude Code 터미널에서 /mcp → 자동 동기화 확인

→ 별도 npm 설치·설정 파일 편집 불필요
→ 셋업 약 1~2분 (1회성)
→ 공식 출처: https://code.claude.com/docs/en/mcp.md (섹션 9 "Use MCP servers from Claude.ai")

[4] 보안·권한 관리

▶ claude.ai 도구별 권한 토글 (영상에서 시연)
· claude.ai → 사용자 지정 → 커넥터 진입
· 우측에 연결된 MCP 도구 목록 표시
· 도구별 개별 권한 설정 가능
· 읽기 전용 도구 / 쓰기·삭제 도구 분류
· "항상 허용" / "개별 차단" / "사용자 정의" 토글
· 필요한 만큼만 켜고 나머지는 차단
→ 수시로 권한 부여·해제 가능

▶ 기본 안전장치 — Gmail 자동 발송 차단
· AI가 초안만 생성, 발송은 사람이 직접 클릭
· 의도치 않은 메일 폭주 방지
→ 100% 자동을 기대했다면 이 부분은 미리 인지

▶ 권한 해지 (커넥터 자체)
· claude.ai → 사용자 지정 → 커넥터
· 해당 커넥터 클릭 → Disconnect
· 즉시 연결 해제
→ 이상 신호 시 즉시 차단 가능

▶ 초기 운영 권장
· 테스트 단계: 별도 구글 계정으로 먼저 연결
· 안정 확인 후 메인 계정으로 이동
· 민감 계정(회사·법인)은 별도 계정 분리 권장
