# 클로드 코드 완벽 가이드 — 코딩 몰라도 15분이면 됩니다

▶ 영상: https://youtu.be/lOf-l0ECuMc

---

[1] 영상에 나온 CLAUDE.md 지침 구조 (블로그 작성용 예시)

▶ 7개 섹션
  · 역할 — AI가 수행할 역할 정의
  · 톤 — 문체·어조
  · 구조 — 본문 레이아웃
  · SEO — 검색 키워드·메타
  · 인포그래픽 — 한 장 요약 이미지 (HTML → Playwright 캡처 → PNG)
  · 출처·브랜딩
  · 저장 경로 — 블로그 파일과 같은 폴더에 같이 저장

▶ 금지 사항 (AI 티 방지)
  · AI 문체
  · 영어 병기 — 예: "언어 (language)" 식 괄호 병기 금지
  · 근거 없는 수치 — 할루시네이션 방지

※ 팁: 지침 파일은 클로드 코드와 대화하면서 같이 만드는 게 더 효율적
  "CLAUDE.md 만들어줘. 내 규칙은 이렇게: …" 형식으로 대화 시작

[2] 시청자 시작 가이드 — 3단계

▶ 1단계: 반복 작업 1개 식별
  · 매번 GPT에게 같은 설명 반복하는 업무 하나 고르기
  · 예: 블로그 톤·리포트 구조·이메일 문체

▶ 2단계: CLAUDE.md 지침 파일로 정리
  · [1]의 7개 섹션 + 금지 사항 기준
  · 빈칸 있어도 OK — 대화하면서 채움

▶ 3단계: 한 줄 명령어로 재사용
  · "블로그 작성해봐" / "이 엑셀 분석해줘" 식 짧은 명령
  · 지침에 따라 매번 같은 퀄리티로 산출
