📘 노트북LM 사용법 — 자료 1개로 9가지가 나오는 구글 AI 노트

▶ 노트북LM이란
  · 구글이 만든 "내 자료 전용 AI 노트"
  · 내가 올린 문서 안에서만 답변·작업 → 할루시네이션·수치 오류 가능성 매우 낮음
  · 무료 플랜: 노트북당 소스 50개

▶ 진입 방법 (구글 생태계 장점)
  · 제미나이 사이드바 → 새 노트북 → 자동으로 노트북LM 진입
  · 또는 notebooklm.google.com 직접 접속
  · 구글 계정 하나로 둘 다 로그인

🎛 스튜디오 9기능 한눈에

자료 1개를 올려두면 아래 9가지가 다 뽑힙니다.

  1. AI 오디오 오버뷰 — 두 명이 대화하는 팟캐스트
  2. 슬라이드 자료 — PPT (.pptx 직접 다운로드) ← 이번 편 메인
  3. 동영상 개요 — 설명 영상
  4. 마인드맵 — 개념 구조 시각화
  5. 보고서 — 텍스트 정리 문서
  6. 플래시카드 — 학습용 암기 카드
  7. 퀴즈 — 자동 생성 문제
  8. 인포그래픽 — 한 장 시각 요약
  9. 데이터 표 — 표 형태 정리

📊 슬라이드 자료 (.pptx) 만드는 법

[1단계] 소스 등록
  · 새 노트북 만들기 → 소스 영역에 자료 드래그 (또는 드라이브 import)
  · 제미나이로 미리 만든 강의 내용을 그대로 올림

[2단계] 옵션 선택 (오른쪽 패널)
  · Detailed Decks — 텍스트 풍부 독립형 (읽는 자료용)
  · Presenter Slides — 핵심 메시지 발표용 (강의·발표 자리)

[3단계] 생성 (60~90초 대기)
  · 슬라이드별 제목·본문·시각 요소 배치까지 자동 잡힘
  · 폰트 크기·여백·색 조합 그대로 발표해도 어색하지 않음

[4단계] 다운로드
  · 옵션 더보기 → PDF 또는 PPTX 선택
  · .pptx 받으면 파워포인트·키노트에서 자유 편집

✏️ 슬라이드 수정 — 대화하듯 다듬기

각 슬라이드 "수정" 버튼 누르면 자연어로 명령 가능. 자주 쓰는 3종:

  · 데이터 추가
    "이 슬라이드에 구체 숫자나 사례 하나 더 넣어줘"

  · 텍스트 압축
    "이 슬라이드 본문을 세 줄 이내로 줄여줘"

  · 톤 조정
    "리포트 말투 말고 강의 톤으로 다시 써줘"

→ 수정 쌓기 가능. 처음부터 다시 안 만들어도 됨.
→ 원하는 방향 안 잡히면 .pptx 받아서 직접 손보는 게 빠름.

🎁 보너스 — 같은 자료로 다른 포맷

▶ 마인드맵
  · 개념 구조를 트리로 펼쳐줌
  · 강의 전 흐름 잡기 / 청중에게 지도 먼저 보여줄 때

▶ 인포그래픽
  · 한 장짜리 시각 요약
  · 블로그 썸네일 / SNS 카드 / 강의 정리 슬라이드 재활용

→ 오디오 오버뷰·플래시카드·퀴즈도 같은 방식으로 한 번씩 눌러보세요.

🔧 제미나이 프롬프트 (강의 내용 생성용 · 보조)

"[주제]"라는 주제로 15분짜리 강의 자료에 들어갈 내용을 만들어줘.
섹션 5~8개, 각 섹션마다 핵심 메시지 한 줄과 설명 2~3문장, 예시 하나씩.

→ 조건 3요소 (섹션 수 · 각 섹션 구성 · 예시) 명시하면 품질 확 올라감.
→ 제미나이 결과를 노트북LM 소스로 그대로 사용.

⚠️ 노트북LM 한계 (영상 정합)

  1. 이미지 생성이 많아지면 자료 생성 속도 느려짐
     · 첫 디자인 생성 때 한 번에 잘 잡는 게 중요
     · 간단한 수정은 .pptx 받아서 직접 처리

  2. 디자인 템플릿이 정해져 있음
     · 기본 퀄리티는 발표 가능 수준
     · 브랜드 컬러·폰트 맞춰야 하면 .pptx 편집으로 마무리
