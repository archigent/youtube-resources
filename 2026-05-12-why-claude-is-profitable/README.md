# 클로드만 유일하게 흑자인 이유 — 실리콘밸리 5년의 여정

▶ 영상: https://youtu.be/MCd8l6B37NQ

---

[1] 한 줄 요약

▶ 2026년 4월, 매출로 OpenAI를 추월한 회사는 Anthropic
  · 1년 반 만에 ARR 30배 (10억 달러 → 300억 달러 / 약 42조 원)
  · AI 회사 중 처음으로 매출 마진 흑자 전환 (-94% → +40%)
  → 5년 전 OpenAI를 떠난 7명이 정한 3가지가 답을 한 사례

[2] 시작 — 2021.01 다리오의 결심

▶ 떠난 7명
  · 다리오 아모데이 — 당시 OpenAI 연구 부사장 (GPT-2·3 핵심)
  · 누나 다니엘라 아모데이 — 안전 정책 부사장
  · 임원 5명 추가, 7명 모두 한날한시에 사표

▶ 떠난 이유
  · 다리오 인터뷰: "모델 크기만 키우면 되는 게 아니더라"
  · 안전을 진지하게 다루는 회사가 따로 필요하다

[3] 회사 이름과 3가지 베팅

▶ Anthropic = 그리스어 안트로포스 (인간)
  · 일반 회사 X, 공익법인 등록
  · 안전을 정관에 의무로 명문화

▶ 5년 후 게임을 가른 3 베팅
  · 안전 — 정관 명문화 + RSP 위험도 1·2·3 단계
  · B2B — 일반 소비자 X, 기업·개발자 라이선스
  · 단일 제품 — Claude Code 하나에 화력 집중

[4] 2024년 — 작은 시장 큰 적자 무명

▶ 결과
  · 매출 3억 8,100만 달러 (OpenAI 10분의 1도 안 됨)
  · 매출 마진 마이너스 94퍼센트
  · 1달러 받을 때마다 1달러 94센트 나감

▶ 시점
  · ChatGPT 폭발, OpenAI 매출 폭발
  · Anthropic 컴퓨팅 비용 매출의 2배
  · 5년 베팅이 다 잘못된 선택처럼 보이던 자리

[5] 2025 — Claude Code 출시 (반전 시작)

▶ 2025.05 Claude Code 출시
  · 출시 6개월 만에 매출 10억 달러 (한화 1조 4천억)
  · ChatGPT가 같은 매출 찍는 데 걸린 12개월의 절반

▶ ARR 폭발
  · 2024.12: 10억 달러
  · 2025.07: 40억
  · 2025.12: 90억
  · 2026.02: 140억
  · 2026.04: 300억 달러 (42조 원)

▶ V자 마진 전환
  · 2024년 -94%
  · 2025년 +40%
  · AI 회사 중 매출 마진 흑자 1호 (단, 회사 전체 흑자는 2028 목표)

[6] 5년 베팅의 답

▶ B2B
  · Claude Code가 기업 고객 라이선스 가져옴
  · 한 회사 = 개발자 수십~수백 명 단가

▶ 단일 제품
  · OpenAI는 ChatGPT·이미지·음성·로봇까지 분산
  · Anthropic은 Claude Code 하나 집중

▶ 안전
  · 멍청한 짓이라던 게 차별화 무기
  · 한 번 들어오면 락인 (코드 학습 비용)

[7] 2026.04 — 빅테크 절반 + xAI 데이터센터

▶ 알파벳 분기 이익의 절반이 Anthropic 지분 가치
  · 1분기 순이익 626억 달러 중 287억이 Anthropic 평가 이익
  · 아마존도 168억 비슷한 비중

▶ 추가 투자 650억 달러 (91조 원)
  · 아마존 250억 + 구글 400억
  · Anthropic 평가 가치 3,800억 달러

▶ xAI Colossus 데이터센터 임대
  · 라이벌 일론 머스크 xAI한테 통째로 빌림
  · 22만 GPU, 도시 하나 전력급

[8] 트럼프 시험과 정면 돌파

▶ Claude Mythos Preview (비공개 운영)
  · 사이버 보안 능력 인간 전문가 압도
  · 운영체제·브라우저 제로데이 취약점 수천 개 몇 주 만에

▶ 2026.01 베네수엘라 마두로 작전
  · 펜타곤이 "뭐든 합법적 목적으로" 사용 권한 요구
  · 다리오 거부 — "현재 AI는 완전 자율 무기에 신뢰할 만하지 않다"

▶ 2026.02.27 트럼프 직접 명령
  · 모든 연방기관 Anthropic 사용 중단
  · 헤그세스 국방장관 공급망 위험 지정
  · 1789 캐피털 수억 달러 투자 백지화

▶ 같은 4월 매출 OpenAI 추월
  · 압박 정면 돌파한 그 시점에 매출 폭발

[9] 마무리

▶ 5년 전 7명이 정한 3가지 — 안전 · B2B · 단일 제품
▶ 5년 만에 매출 추월 + 마진 흑자 전환 + 트럼프 압박 정면 돌파
▶ 회사 전체 흑자 목표는 2028년
