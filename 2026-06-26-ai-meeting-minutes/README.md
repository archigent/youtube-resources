# AI 회의록 정리, 담당자·기한까지 자동으로 — 클로드 코드

▶ 영상: https://youtu.be/3cxIHfFTFKI

---

[0] 처음 한 번만 — 화자분리용 무료 토큰 (5분)

화자분리는 무료지만, 모델을 받으려면 허깅페이스 토큰 한 번이 필요합니다.
  1. huggingface.co 가입
  2. 모델 약관 동의: pyannote/speaker-diarization-community-1 페이지에서 동의
  3. huggingface.co/settings/tokens → Read 토큰 생성 → 복사
  4. 터미널에서 huggingface-cli login → 토큰 붙여넣기 (1회, 계속 사용)
  → 자세한 건 아래 깃허브 스킬에 그대로 정리해뒀습니다.


[1] 클로드 코드에 줄 지시 (그대로 복붙)

▶ ① 받아쓰기 + 화자분리
  · "이 폴더에 있는 회의 녹음 파일, whisperx로 받아쓰면서 화자분리까지 해줘. 참석자는 N명이야. 누가 무슨 말 했는지 보이게 텍스트로 정리해줘."

▶ ② 오타 보정 + 회의록 작성
  · "받아쓴 스크립트에서 사람 이름·고유명사 틀린 거 고쳐줘. 그리고 이 내용을 회의록으로 정리해줘. ① 결정사항 ② 할 일(누가 말한 기준으로 담당자·기한 포함) ③ 다음 일정. 할 일은 담당자·기한 표로."

▶ ③ 일정 캘린더용
  · "다음 미팅 일정은 구글 캘린더에 바로 넣을 수 있게 날짜·시간·장소·안건 표로 빼줘."


[2] 안 맞으면 말로 고치기

· 화자가 섞임 → "이 부분 ○○님 말인데 화자 잘못 잡혔어. 내용 보고 바로잡고 담당자 다시 매핑해줘"
· 이름·금액 오타 → "'김데표'는 '김대표'야. 이런 받아쓰기 오타 맥락 보고 다 고쳐줘"
· 너무 길다 → "결정사항은 핵심만 3~5줄로"
· 내 양식 → "우리 회사 회의록 양식 [항목] 순서로 바꿔줘"


[3] 쓸 때 팁

· 받아쓰기·화자분리는 100%가 아닙니다 — 중요한 담당자·금액·결정은 원본과 한 번 대조하세요
· 목소리가 비슷한 참석자는 화자가 섞일 수 있어요 → 위 [2]로 바로잡으면 됩니다
· 한 시간 넘는 긴 회의는 녹음을 반으로 잘라 두 번 돌리고 합치면 메모리·시간이 안정적입니다
· 받아쓰기 정확도를 더 높이려면 모델을 large-v3로 (느려지지만 정확)
